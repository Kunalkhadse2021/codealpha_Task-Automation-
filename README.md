# codealpha_Task-Automation-
Task Automation using Python – A Python project that automates daily tasks such as organizing JPG images, extracting email addresses, and scraping webpage titles.
Task Automation Using Python

Project Description

Task Automation is a Python-based project developed to automate simple and repetitive daily tasks. It helps users save time and reduce manual work using Python programming.

Features

File Organizer: Automatically moves JPG and JPEG images into a separate folder.

Email Extractor: Extracts email addresses from text.

Web Scraper: Extracts webpage titles from websites.

Technologies Used

Python 3

OS Module

Shutil Module

Regular Expressions (re)

Requests

BeautifulSoup

How to Run

Install Python 3.

Download or clone this repository.

Open the project folder in VS Code.

Run the Python file using:

python task_automation.py
